# 📈 ISAT Position Trading Dashboard

Dashboard pribadi untuk memantau strategi **position trading piramida terbalik 4 termin** pada saham **PT Indosat Tbk (ISAT.JK)**.

## 🎯 Fitur

- ✅ Harga real-time ISAT.JK (via Yahoo Finance)
- ✅ Widget grafik TradingView interaktif
- ✅ Indikator teknikal otomatis (MA20, MA50, RSI14, Volume)
- ✅ Deteksi fase pasar (Falling Knife, Accumulation Zone, Reclaim Bullish, dll)
- ✅ Proxy deteksi akumulasi bandar
- ✅ Kalkulator piramida 4 termin interaktif (harga editable, status beli tersimpan)
- ✅ Checklist 3 poin sebelum Instant Redeem
- ✅ Panel sentimen & katalis
- ✅ Update otomatis 3x sehari via GitHub Actions (09:35, 12:05, 16:15 WIB)
- ✅ Dark mode, responsif HP & desktop
